# 🎬 AuraVideo Studio — Online Video Aesthetic Color Suite

A high-performance online video color grading and aesthetic filter studio. Powered by vectorized Look-Up Table (LUT) color science and FFmpeg zero-disk in-memory streaming.

### Features
- **36 Aesthetic Presets:** Clean Glow, Warm Intimate Bedroom, Golden Candlelight, Midnight Clarity, Portra 400, Cinematic Teal & Orange, and more.
- **Lightroom-Style Fine Tuning:** Real-time shadow lift (Smart Brightness), highlight recovery, filmic S-curve contrast, temperature, tint, vibrance, bloom, film grain, and edge sharpness.
- **Interactive Before/After Preview:** Inspect individual frames before full rendering.
- **Lossless Audio Pass-Through:** Preserves 100% original video audio stream without re-compression.
